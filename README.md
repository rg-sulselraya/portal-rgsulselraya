# Ruangguru Sulsel Raya · Digital Portal

Lightweight, data-driven application launcher for `rgsulselraya.xyz`.

## Add an application

Add one object to [`apps.js`](./apps.js). The card UI, search, status badge, and responsive layout update automatically.

## Deploy

The site is static and ready for GitHub Pages. The [`CNAME`](./CNAME) file is set to `rgsulselraya.xyz`; point the domain DNS at the GitHub Pages deployment for the repository.
